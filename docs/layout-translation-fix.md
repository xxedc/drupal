# 布局与翻译修复

## 语言切换器

- 桌面端语言按钮用 CSS `order` 排在主题切换（月亮）右侧，默认只显示当前语言，点击展开。
- 移动端抽屉底部、登录/注册上方改为页内展开，不再使用浮层上拉。
- 中文界面：中文 / 英语 / 俄语 / 日语。英文、俄文、日文界面显示该语言中的名称。
- 首页、页脚、文章面包屑、文章列表搜索、站点地图和会员中心空状态里原先写死的路径，改为带语言前缀的 URL。切换语言后沿用 `/en`、`/ru`、`/ja` 前缀。

## 长标题

卡片和列表标题限制为两行（`line-clamp` 加 `max-height`），避免英文、俄文撑开网格。详情页标题改为换行，不截成两行。首页幻灯片标题过长时省略。手机端不再隐藏第 5 张及以后的最新美图。

## 首页重复与数量

首页、美图、文章、视频列表视图增加「当前内容语言」过滤。首页卡片再按节点去重，并读取当前语言译文。最新美图每页 8 条；桌面 4 列两行，平板 3 列，手机 2 列。

## 补译

已发布中文内容的标题和摘要原先已有 en/ru/ja。本次用现有翻译（不覆盖已有译文）补全分类、模特、标签。DeepL 触发 429 后已自动重试并完成。菜单实际 bundle 为 `menu_link_content`，已开启内容翻译；导航文字与界面译文对齐：Photos / Videos / Articles / Models。
